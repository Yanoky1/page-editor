PAGE MASKER — локальная замена текста элементов страницы

Установка в Chrome / Edge / Brave:
1. Распакуйте папку page-masker в постоянное место.
2. Откройте chrome://extensions (для Edge: edge://extensions).
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное» и укажите папку page-masker.
5. Откройте нужную страницу, нажмите значок расширения и выберите «Выбрать элемент пипеткой».
6. Нажмите на текстовый элемент, снова откройте расширение, введите замену и сохраните.
7. Обновите страницу — правило будет применяться снова. Удалить его можно из списка в окне расширения.

Правила и замены хранятся в локальном хранилище браузера и сопоставляются по имени сайта (hostname).
Расширение меняет видимый текст элемента (textContent), а не исходный ответ сервера. Если сайт перерисовывает компонент,
расширение повторно применит правило через наблюдение за изменениями DOM. Сайты, использующие iframe/shadow DOM,
часто меняющие структуру, либо текст внутри сложного элемента могут требовать выбора более узкого элемента.

Пипетка: Escape отменяет режим выбора. Работает на обычных страницах сайтов; системные страницы браузера и страницы
магазина расширений закрыты самим браузером.
